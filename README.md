# ⚡ 雷霆记账

雷霆记账是一款个人记账应用，帮助你记录日常收入与支出、整理账单，并通过统计页面回顾收支情况。应用通过腾讯云 CloudBase 提供账号云端存储与同步；登录同一账号并联网时，账单、分类和持仓数据可在多台设备间同步使用。

本仓库是公开下载页，提供 Windows x64 便携版和投资快照 Skill。应用源码与内部项目资料不放在这里。

## 主要功能

- **记录日常收支**：添加收入或支出，使用分类整理每笔账单。
- **回看账单与统计**：浏览历史账单，并查看收支统计。
- **腾讯云多端同步**：账单、分类和投资持仓与当前登录账号关联，通过 CloudBase 云端同步，便于在多台设备上使用。
- **投资快照 Skill**：把持仓资料整理成快照提案，供你检查。提案需要在雷霆记账中复核并确认后，才会更新账本；估算内容不等于实时行情。
