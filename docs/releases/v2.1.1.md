# 雷霆记账 v2.1.1

## 更新内容

- 周期支出列表显示已选一级/二级分类；订阅表单收起非必要字段。保留旧定投数据，但不再将定投规则自动记为支出。
- 桌面端普通账单、分类与持仓同步改用当前已登录用户的 CloudBase 会话，不在客户端包中依赖服务端管理 API Key。
- 投资持仓新增可核对的历史快照、现金流完整性、浮盈/日收益/累计收益估算、按币种分组的资产占比图和历史市值趋势。
- 数据缺失、云集合缺失、权限或网络错误会显示为不可计算/同步失败；不会把未知数据显示成零或空仓。
- 支出与持仓 Agent Skills 采用宿主中立的 `SKILL.md` 与 JSON 提案协议。Agent 只能生成待审核提案；每次入账都要在应用中单独预览并确认。
- 支持从 Agent 返回的标准 JSON 文件导入提案；应用会将其放入当前登录用户的待审目录，再走相同校验和确认流程。

## 投资收益口径

收益依据用户确认的低频快照和现金流记录估算，不提供实时行情或 K 线。成本、估值日期、币种、历史基线或现金流记录不完整时，相关指标会显示不可计算及原因。持仓快照没有提到的资产不会被视为卖出或删除。

## CloudBase 部署要求

客户端普通数据同步使用登录用户身份和用户范围权限规则。投资同步要求目标 CloudBase 环境预先存在 `investment_positions` 和 `investment_snapshots` 集合，并限制用户只能访问自己的数据。客户端不会自动创建集合。

本版发布前未连接生产 CloudBase，因此仓库和安装包不能证明目标环境的集合或权限规则已经配置。集合缺失时，应用会保留本机数据并显示迁移/同步失败状态；部署人员应先在隔离环境完成跨账号读写验证，再按目标环境流程配置。
