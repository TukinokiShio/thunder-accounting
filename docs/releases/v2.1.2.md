# 雷霆记账 v2.1.2

## 更新内容

- 投资持仓提升到页面首屏主内容区，资产分配图表放在持仓列表之后；持仓按市值从高到低展示，缺失估值的项目排在末尾。
- 云端读取失败时明确显示云端状态未知和本机可见数据，不再把同步失败呈现成已确认空仓；重试入口和错误详情收敛到同步状态区。
- 投资提案的确认/拒绝操作移到卡片顶部摘要之后；完整字段差异、保留项目和技术信息默认收起，减少审核时的滚动和无关细节。
- CloudBase 会话只在明确的访问令牌过期错误下刷新一次，并在重新绑定后复核同一用户身份；错误码冲突或未知错误均失败关闭，不触发刷新。

## 验证范围

- 64 个测试文件、613 项测试通过；TypeScript 类型检查通过。
- Windows x64 构建与 Inno Setup 安装包编译通过。安装器在固定验收目录静默安装成功，退出码为 0；安装后 `app.asar` 中的版本为 2.1.2。
- 本版没有连接生产 CloudBase 或启动已安装应用。云端同步仍需在用户环境完成验收。
