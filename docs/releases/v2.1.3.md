# 雷霆记账 v2.1.3

## 更新内容

- 按用户选定的 B 方向，将资产配置仪表盘和图表移到当前持仓卡片之前；持仓卡片与原有数据计算口径保留。
- 扩展 CloudBase 安全错误码识别，覆盖常见数据库权限、集合缺失、超时和请求错误，并读取 SDK 的 `errCode`、`response.data`、`cause` 字段。
- 未知或相互冲突的错误仍显示通用码，不展示错误消息、令牌或请求内容。`cloud_unknown_error` 本身不能说明生产环境的具体故障原因。

## 验证范围

- 定向测试：2 个文件、13 项通过；全量测试：64 个文件、613 项通过；TypeScript 类型检查通过。
- Windows x64 构建、Inno Setup 编译、静默安装通过；固定验收目录 `exe` 的 `app.asar` 版本为 2.1.3。
- 便携 ZIP 包含 `resources/app.asar` 与 `雷霆记账.exe`；安装包与 ZIP 的 SHA-256 已记录。
- 未启动应用、访问生产 CloudBase 或读取/修改真实账本。云端同步仍需在用户环境复验。
