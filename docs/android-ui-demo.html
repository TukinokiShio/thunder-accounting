本次终审确认的决策

决策项结论
底部导航形态采纳 方案 B —— 4 Tab（首页 / 账单 / 统计 / 我的）+ 中央凸起「记一笔」。与桌面侧栏 5 项一一对应，记账入口更突出。
当前页指示改为 文字 + 图标发金棕色光，不用色块。顶部可切换「关 / 弱 / 标准 / 强」四档，请挑定一档（默认「标准」）。
分类删除需要二次确认。确认框显示子类数量，并说明已用该分类的账单不会被删、只会变成「未分类」。
拖动 / 删除入口仅编辑模式内可用。普通模式点分类只做重命名 / 改图标。
安全区：手机壳上下两条虚线是 env(safe-area-inset-top/bottom) 的实际占位。刘海与手势条会吃掉这部分高度 —— 桌面端没有这个概念，所以底部导航、FAB、以及「记一笔」弹窗的底部按钮都必须算进去，否则会被手势条压住。
触控目标：Tab 56px、拖动把手与删除按钮 44px，均 ≥ Android 无障碍下限 44dp。
关于 hover：桌面端部分反馈靠鼠标悬停（如分类删除按钮只在悬停时出现），触屏没有悬停，已全部改为常显或按下态。
说明：本页仅为视觉方案确认用的静态 demo，数据是假的，未接入本地库或云端。
